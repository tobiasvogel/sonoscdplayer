# UI translations

The SonosCDPlayer OLED language is selected **explicitly**, never from
the host's locale or an automatic language guess.

## Select the language

The initial language comes from the existing UI TOML file:

```toml
[ui]
language = "de"
```

The current production default path is
`/home/pi/sonoscdplayer/ui.toml`; the OLED service can override it via
`--ui-config`. The encoder menu's **Language / Sprache** item lets the
user choose a different language for the current session. This does **not**
rewrite TOML. On restart, the configured language is loaded again.

## Add a new language

1. Copy `src/sonos_ui/i18n/locales/en.json` to a new file such as
   `src/sonos_ui/i18n/locales/fr.json`.
2. Translate all values, preserving **every translation key** and all
   format placeholders (for example `{count}`, `{name}`).
3. Set `language.name` to the language's own name, e.g. `Français`.
4. Run `PYTHONPATH=src python3 -m unittest discover -s tests -p 'test_sonos_ui_i18n.py' -v`.
5. Select it through the OLED menu, or set `[ui].language = "fr"`.

No Python list, menu entry, or renderer switch needs modification. Locale
filenames are discovered as **available options only**; that is not automatic
language selection. English is the fallback for an unknown configured code.
The missing translation ID fallback is also English; the tests require
identical keys/format placeholders for each checked-in language.

Names returned by Sonos (speaker/device names) and user-authored music
metadata are **not translated**. Protocol commands, state codes, file paths,
CLI option strings, and diagnostic exceptions are not UI copy and must not
be localized.

## Compatibility and safety

- Existing `de` and `en` language choices are preserved.
- Language switching remains a local display-only action: no Sonos writes,
  service restart, hardware access, or configuration modification.
- The legacy OLED status screen and unnamed-speaker fallbacks now use the
  same translation catalog.
- This is **not** a configuration migration or a permission to edit
  production `ui.toml`.
