# Display languages and translations

SonosCDPlayer supports multiple languages for its display interface.

English and German are currently included. Additional languages can be added through JSON translation files without changing the display or menu implementation.

## Selecting a language

The initial display language is set in the UI TOML file:

```toml
[ui]
language = "de"
```

Use `language = "en"` for English.

An example is provided at [`config/ui.example.toml`](../config/ui.example.toml). The location of the active UI configuration depends on the installation; the display service supports `--ui-config` to select a file.

The language can also be changed from the display's **Language / Sprache** menu. This changes the **current session only** and does not rewrite the configuration file. When the display service restarts, it loads the configured initial language again.

Language selection is independent of the operating system's locale settings.

### Shutdown and restart screens

The screens shown while shutting down or restarting ("Wird heruntergefahren…", "Wird neu gestartet…", "Bitte warten") are drawn by small C programs that run after the Python services have stopped. Their text is rendered **at build time** in the language configured in `ui.toml`; the icons come from the images in `src/data/`. The text uses the bundled font Encode Sans Semi Condensed (`src/fonts/`, SIL Open Font License 1.1, see `src/fonts/LICENSE-EncodeSans-OFL`), which is only needed for the build. A language chosen in the display menu does not affect these screens.

After changing `language` in `ui.toml`, rebuild and reinstall the shutdown programs:

```sh
sh tools/build_shutdown_renderer.sh
sudo install -m 0755 build/shutdown/sonoscdplayer-shutdown-display /usr/local/libexec/
```

If the experimental exitrd is installed, also run `sh tools/manage_experimental_exitrd.sh --uninstall` followed by `--install`.

Every translation must fit these screens: the build fails if a text does not fit on two lines.

## Adding a new language

Translation catalogs are stored in `src/sonos_ui/i18n/locales/`.

1. Copy [`en.json`](../src/sonos_ui/i18n/locales/en.json) to a new locale file such as `fr.json`.
2. Translate the values, preserving **all translation keys**.
3. Preserve formatting placeholders such as `{count}` and `{name}`.
4. Set `language.name` to the language's own name, for example `Français`.
5. Run the translation tests.
6. Select the language through the display menu or configure it in the UI TOML file.

Run the tests from the repository root:

```sh
PYTHONPATH=src python3 -m unittest discover \
    -s tests -p 'test_sonos_ui_i18n.py' -v
```

Available languages are discovered from the JSON filenames. No additional Python registration or menu changes are necessary.

Checked-in translations must provide the same keys and formatting placeholders as the English catalog.

## Translation behaviour

An unknown configured language falls back to English. Individual missing translations also fall back to English where the English catalog provides the key.

The catalog covers user-facing display text, including playback information, menus, status notices, and fallback labels.

The following are not translated:

- Sonos speaker and device names.
- User-provided music metadata.
- Internal protocol commands and state identifiers.
- File paths, CLI option strings, and diagnostic messages.

Switching display language is a local UI action. It does not change Sonos playback, modify configuration files, or restart services.

## Contributing translations

Translations are welcome. Use the English catalog as a reference, keep wording concise for small displays, and run the translation tests before submitting changes.

Also review translations visually on the display when possible: successful automated tests do not guarantee that every label fits the available screen space.
